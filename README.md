# ⚡ Real-Time System Monitor Dashboard

A live system monitoring dashboard built with Node.js and vanilla JavaScript.
Displays real-time CPU, Memory, and Disk usage with animated gauges that update every second.

## Features
- Live CPU load gauge
- Memory usage with GB breakdown
- Disk usage with storage breakdown
- Animated circular gauges
- Updates automatically every second
- Clean dark mode UI

## Tech Stack
- Node.js
- Express.js
- systeminformation (npm library)
- HTML, CSS, JavaScript (vanilla)

## How to run
npm install
node server.js

Then open http://localhost:3000 in your browser.
